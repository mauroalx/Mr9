# Design system — Fiber control room

Identidade densa para operação ISP (centenas de provedores), não landing.

## Tipografia

- UI: **IBM Plex Sans**
- Técnico (serial, paths, IPs): **JetBrains Mono**

## Cor

- Graphite + teal fibra (`--brand` / `--brand-2`)
- Semânticos: `--ok` / `--warn` / `--crit`
- Light-first; dark opcional futuro

## Layout

- Sidebar estreita + topbar com **ACS switcher**
- KPI strip no dashboard (estilo BI)
- Painéis com borda leve; cards só para interação
- Densidade: `text-sm` / labels muted / grids label-value

## Não fazer

- Purple gradient / glow AI
- Hero marketing na área logada
- Chamar GenieACS do browser
- Copiar branding Master OLT
